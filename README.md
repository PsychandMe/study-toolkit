STUDY TOOLKIT: INSTALL AND OFFLINE GUIDE

PC, quickest (no install): double-click index.html. It opens in your browser and works offline.
Fonts: Lexend and Atkinson Hyperlegible load online the first time; offline it falls back to your device's default font.

Installable app (PC, Android, iPhone/iPad): upload this whole folder to any free HTTPS host
(GitHub Pages, Netlify Drop, Cloudflare Pages), then open the link once while online.
- Chrome/Edge (PC and Android): use Install app in the address bar or menu.
- iPhone/iPad: Safari, Share, Add to Home Screen.
After the first visit it works with no connection.

Your data stays on the device (browser storage). Use Settings, Back up or move your data, to copy it between devices.
